## 全仓与平台限制

本次定向矩阵通过，**全仓测试仍未证明全部通过**。较早 eBPF 工作树 `456481bad87e01b7cd81a8348c885e7bcbb67720` 的一次全仓执行记录为：64 个包通过、15 个包失败、47 个包跳过或无测试；测试/子测试事件有 3,041 pass、39 fail、21 skip。这不是最终提交的重新全仓计数，也不是去重后的顶层用例数。

其中新引入的 `TestFirewallBlockModifyValidatesAndNormalizes` 元数据编辑回归已修复并定向通过；其余包含既有 API/service 夹具、Kafka/工具链签名、Go vet、外部依赖、防火墙权限及断言差异，尚未逐项完成最终提交的全仓对照。干净源码快照只有前端 `.gitkeep`，与嵌入正式前端资源的部署构建不同，也导致额外静态资源测试失败。不能把这些失败全部笼统标为上游问题。

Windows / Go 1.27.3 的 CLI 编译出现 `SQLiteConn.Backup undefined`，在未修改的缓存阶段 `c8d96c7` 上复现相同错误。当前交付确认的是 Linux amd64/ARM64 路径，不宣称本次完成全部桌面平台构建。Docker 镜像与 Compose 未进行本轮实际部署验收。
